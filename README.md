# 🚀 Oluwafeyijimi — Portfolio Website

A high-performance, agency-grade portfolio website showcasing software engineering projects, motion graphics work, and official services under **SypherTec**.

Designed with a dark glassmorphic aesthetic, sleek glow accents, and subtle particle interactions inspired by modern tech brands like Apple and Linear.

---
# Website Link
   https://jimmmzzzzz.github.io/Portfolio/#
---

## ✨ Features

- **Agency Visual Identity**: Dark theme (#050505) paired with Electric Blue (#00AEEF) glow accents and glassmorphism overlay effects.
- **Interactive Particle Canvas**: Lightweight, dynamic 2D canvas background running in pure JavaScript.
- **Smooth GSAP Animations**: Custom scroll-triggered section transitions and entrance reveals powered by GSAP.
- **Fully Responsive**: Grid layouts built with native CSS Grid/Flexbox to adjust seamlessly across mobile, tablet, and desktop viewports.
- **Zero Heavy Framework Overhead**: Built with lightweight HTML5, vanilla JS, and modern CSS3 for optimal loading speeds and performance.

---

## 🛠️ Tech Stack

- **Structure**: HTML5
- **Styling**: CSS3 (Variables, Flexbox, Grid, Dynamic Glassmorphism, Glow effects)
- **Scripting & Animations**: JavaScript (ES6+), GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Typography**: Space Grotesk (Headings), Inter (Body)
